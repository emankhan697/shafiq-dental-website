# Dr. Shafiq Dental Associates Website

A responsive, public-facing informational website for Dr. Shafiq Dental Associates in Islamabad. It has no patient accounts, dashboards, or backend; appointment requests are composed in WhatsApp.

## Run locally

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local address shown in the terminal.
4. Run `npm run build` to create a production build in `dist/`.

## Website sections

- About the clinic and dental team
- Dental services and reasons to choose the clinic
- Clinic gallery and public review rating summary
- Appointment request form that opens WhatsApp
- Contact details, map, directions, phone and WhatsApp links

## Before publishing

- Replace the illustrative clinic and doctor photos with approved images from the practice.
- Confirm the business listing and reviews URL, clinic hours, and any additional factual details.
- Google Fonts, Unsplash photos, Google Maps and WhatsApp links require an internet connection.
